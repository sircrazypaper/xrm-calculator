# xRM Calculator
This is an improved rep max calculator. It uses the Epley's formula, and has functionalities for both olympic lifts, as well as normal lifts. It also has RIR in the calculations, so you can get more accurate numbers for rep maxes at different effort levels.

I made the calculation scripts myself, and used Claude to guide me through how to make the app, although I did all of the coding myself(I have never used streamlit before).

I hope you like it :)
